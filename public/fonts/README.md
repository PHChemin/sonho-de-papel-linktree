# Fontes self-hosted (`@font-face` em `src/styles/main.css`)

| Arquivo | Família | Uso |
| --- | --- | --- |
| `AromaVintage-Regular.otf` (+ `.ttf`) | Aroma Vintage | Headline |
| `Aileron-Regular/SemiBold/Bold.woff2` | Aileron (CC0) | Marca / títulos |
| `Carlito-Regular/Bold.woff2` | Carlito ≈ Calibri (OFL) | Corpo |

**Aroma Vintage:** o arquivo gratuito costuma ser “personal use”. Para o site da cliente em produção, confirme a **licença comercial** com a foundry ([TimelessType / MyFonts](https://www.myfonts.com/collections/aroma-vintage-font-timelesstype-studio)).
